# BLOCKERS.md

> Hambatan yang mencegah tiket aktif selesai pada sesi kerja tersebut. **Wajib dicatat sebelum mengakhiri sesi** jika ada blocker — jangan biarkan blocker hanya "diingat di kepala" (lihat `WORKFLOW.md`).

## Format Entri

```
### BLOCKER-{nomor} — {ringkasan singkat}
- Tiket terdampak: {ID tiket}
- Tanggal ditemukan: {tanggal}
- Deskripsi: {penjelasan hambatan}
- Dibutuhkan untuk resolve: {apa yang perlu diputuskan/dicari/diselesaikan}
- Status: Open / Resolved
- (jika Resolved) Resolusi: {bagaimana diselesaikan, tanggal}
```
